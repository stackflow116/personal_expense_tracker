# Personal Expense Tracker

A full-stack web application for managing personal finances efficiently. Track your income, expenses, monthly budgets, and spending trends in one place with a clean and user-friendly dashboard.

## Features

- Add, edit, and delete income and expense records
- Categorize transactions (food, rent, transport, entertainment, etc.)
- View total balance, monthly spending, and monthly income
- Filter transactions by date, category, or type
- Budget tracking for personal financial goals
- Dashboard with analytics and spending summaries
- Secure authentication and user-specific data
- Responsive design for desktop and mobile devices

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS or Bootstrap
- Axios
- Chart.js / Recharts (for dashboard insights)

### Backend
- Node.js
- Express.js
- MongoDB / PostgreSQL
- JWT Authentication
- REST API

## Project Architecture

The app is structured as a full-stack application with:
- Frontend: user interface and dashboard
- Backend: API layer, authentication, and business logic
- Database: persistent storage for user and transaction data
